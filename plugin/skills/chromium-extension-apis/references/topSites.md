# topSites

**Permission string:** `topSites`
**API namespace:** `chrome.topSites`

## Interface (Chromium 153.0.8010.18)

Use the `chrome.topSites` API to access the top sites (i.e. most visited sites) that are displayed on the new tab page. These do not include shortcuts customized by the user.

**Functions**
- `topSites.get()` — Gets a list of top sites.

## What it's for (broad)

Read the most-visited sites that back the new-tab page. Broadly: custom new-tab and launcher UIs, quick-access dashboards, and usage-aware shortcuts.
