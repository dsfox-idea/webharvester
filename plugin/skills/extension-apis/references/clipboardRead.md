# clipboardRead

**Permission string:** `clipboardRead`
**API namespace:** capability permission — no dedicated `chrome.*` namespace

## Interface (official)

Lets the extension paste items from the clipboard using the web platform Clipboard API.

## What it's for (broad)

Read the system clipboard through the Clipboard API from extension pages. Broadly: paste-aware tools, snippet expanders, clipboard history and sync, and importers that pick up whatever the user copied elsewhere.
