# clipboardWrite

**Permission string:** `clipboardWrite`
**API namespace:** capability permission — no dedicated `chrome.*` namespace

## Interface (official)

Lets the extension cut and copy items to the clipboard using the web platform Clipboard API.

## What it's for (broad)

Write to the system clipboard reliably, including from background contexts. Broadly: copy buttons, formatters and converters, share/export flows, and automations that hand data to other apps through paste.
