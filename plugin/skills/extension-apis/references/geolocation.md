# geolocation

**Permission string:** `geolocation`
**API namespace:** capability permission — no dedicated `chrome.*` namespace

## Interface (official)

Allows the extension to use the geolocation API without prompting the user for permission.

## What it's for (broad)

Use the geolocation API without the usual per-use prompt. Broadly: location-aware automation, region defaults, mapping and travel tools, and logging that would be too noisy if it prompted each time.
