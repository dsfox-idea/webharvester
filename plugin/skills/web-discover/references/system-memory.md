# system.memory

**Permission string:** `system.memory`
**API namespace:** `chrome.system.memory`

## Interface (Chromium 153.0.8010.18)

The `chrome.system.memory` API.

**Functions**
- `system.memory.getInfo()` — Get physical memory information.

## What it's for (broad)

Read total and available physical memory. Broadly: performance monitoring, back-pressure on memory-heavy work, and capacity reporting.
